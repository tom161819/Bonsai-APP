# Bonsai deník

Aplikace pro pěstitele bonsají: přehled úkolů, sbírka stromů s fotkami a deníkem péče, připravovaná mapa yamadori.

Prototyp bez build kroku. Stačí otevřít `index.html` v prohlížeči (nebo zapnout GitHub Pages). Data se ukládají lokálně v prohlížeči (IndexedDB), zálohu lze stáhnout jako JSON.
